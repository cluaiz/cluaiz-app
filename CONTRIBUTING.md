# Contributing to the Cluaiz App

Thank you for your interest. The App is **in development** and is released after the
[Engine's](https://github.com/cluaiz/cluaiz) pre-release ends.

## What we accept now

| Contribution | Accepted now |
| :--- | :--- |
| Bug reports, when you build and try the App from source | **Yes**, [open an issue](https://github.com/cluaiz/cluaiz-app/issues/new/choose) |
| Feedback, ideas, "this is missing" | **Yes** |
| Questions and discussion | **Yes**, in issues or on [Discord](https://discord.gg/mab8kBURz) |
| Pull requests with code | **Not yet** |

**Why no pull requests yet:** the App changes every day while it is built, and the Engine it talks to is still in
pre-release. Merging outside code now would mean asking contributors to redo their work again and again. Pull
requests open after the App's first release. Until then, a pull request is closed with thanks, and an issue that
describes the same change is just as useful.

**Tools are open to contributions now** in [cluaiz-tools](https://github.com/cluaiz/cluaiz-tools/blob/main/CONTRIBUTING.md).

## A good report

Say which commit you built, your OS, the Engine version (`cluaiz --version`), what you did, what you expected and
what happened. A screenshot helps. Remove tokens, keys and personal paths first.

Security problems are never reported in public. See [SECURITY.md](SECURITY.md).

## Stay in touch

Join the [Discord](https://discord.gg/mab8kBURz) to talk about the App, or to contribute once pull requests open.

## Code of conduct

Be respectful and helpful. The [Code of Conduct](https://github.com/cluaiz/cluaiz/blob/main/CODE_OF_CONDUCT.md) of
the Cluaiz project applies here too.
